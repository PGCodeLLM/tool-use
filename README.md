# LLM Tool Use Improvement

Data curation and analysis techniques to improve LLM tool use, in particular teminal/shell use.

#### `/shell-use`

Fast-thinking data on terminal/shell use.

#### `/shell-use-openhands`

Same fast-thinking data from `/shell-use` which was used for distillation from DeepSeek-v3.1 using OpenHands scaffold. Includes analysis and processing scripts in `src/`, example training config .yaml files for SFT jobs in `train_cfg/`, as well as post-processed .JSONL data files in `data/`
